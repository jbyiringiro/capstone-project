Uko Vuga ibika amakuru · Privacy policy

IkinyarwandaEnglish

Version 1.1, 5 November 2026. Vuga is a student prototype made by Josue Byiringiro at the African Leadership University, Kigali.

The short version

  1. The board works with no account. Everything a child does stays on this device unless an adult chooses to send it.
  2. On the server a child is known only by a code such as P-01: never by name, photo or voice.
  3. Photos, recorded voices and custom words you add never leave this device.
  4. No selling, no adverts, no trackers. Vuga loads no analytics or advertising code.
  5. You can delete your account and its child data: Umurezi → Kwinjira → Siba konti yanjye. Minimal identifiers of deleted email accounts remain to prevent stale requests recreating them.
  6. Only a parent or guardian, or a teacher or therapist with the parent's agreement, sets up a child's profile.

1. What stays on this device

Vuga keeps these in the browser's storage (IndexedDB) on the phone or tablet, and nowhere else:

  • each child's profile: a code such as P-01, or the name the family uses;
  • custom words, with their photos and recorded voices;
  • the messages the child builds, with each tap and its time;
  • picture-game results, board settings and the child's own next-word history;
  • the caregiver PIN and recovery code, kept only as salted PBKDF2 digests, never as the PIN itself.

Speech, sentence building and next-word suggestions are all worked out on the device. Clearing the browser's data deletes all of this, so download the messages first if you need them (Ohereza → Kuramo ubutumwa).

In the account copy and synced messages the server refuses children’s names, free text, photos and recordings, so they cannot be sent by mistake. A message that uses a custom word stays on the device, because its picture or label may show a family member.

In the Neon deployment, the browser sends account requests to the Vuga API over HTTPS. The API forwards the required name, email, password or verification code to Neon. Vuga does not store or log passwords or verification codes. Neon manages password credentials and sessions. The browser stores an encrypted session token and the linked account identity; only the API can open that token. The separate device PIN stays on the device. After cloud deletion, Vuga retains the provider identifier, provider user ID, former Vuga account ID and deletion time while the service operates, so an old session cannot recreate the account. This ledger contains no email, name, password, PIN or child data.

3. Who else handles data

  • Neon stores the cloud database and handles email signup, verification and password reset for the Render + Neon deployment. It receives your adult name, email and password when needed for authentication. Its shared email sender is used for capstone testing. See Neon privacy information.
  • Render hosts the website and Vuga API. The Neon deployment does not send SMS or use Firebase authentication. Older deployments may still use their documented legacy account providers.
  • Hosting. Rwandan law asks for personal data to be stored in Rwanda unless the National Cyber Security Authority (NCSA) has authorised storage abroad (Law No. 058/2021, Article 50). The public test server is in Europe, so it is not open to families' accounts. Before any family links a number, Vuga will register with NCSA as a data controller (Article 29) and store accounts in Rwanda or with NCSA's authorisation.

We never sell or share data for advertising, and we do not use children's messages to train models. If that ever changes, we will ask for consent first.

4. Children

Vuga is used by children but set up by adults. Under Rwandan law a child's personal data under 16 needs the consent of a person with parental responsibility (Law No. 058/2021, Article 9). Only a parent or guardian, or a teacher or therapist with the parent's agreement, should create a child's profile or link it to an account. The caregiver area is behind a long press and a PIN, so a child cannot change settings or send data.

6. Security

The device PIN is hashed locally, and repeated wrong tries temporarily lock it. Email accounts use a separate password managed by Neon in the selected deployment; the API checks encrypted session tokens, verified email and current provider session state. The Neon deployment requires session revocation on password reset; the local PIN is independent. Legacy phone accounts hash their cloud PIN with bcrypt, lock after five wrong tries and revoke old sessions when that PIN changes. If personal data on the server were ever exposed, we would tell NCSA within 48 hours (Article 43) and tell the caregivers affected.

7. Research study

The adult usability study at Autisme Rwanda (ALU Research Ethics Committee approval SEPT26-BSE-048) has its own consent form. It records only a participant code and the taps made on the study tablet; no children take part.

8. Terms of use

Vuga is a free prototype. It supports communication but does not replace a speech therapist, and its Kinyarwanda words and voices still await review by native speakers. The code is under the MIT licence. The pictograms (ARASAAC, CC BY-NC-SA 4.0) and the synthetic voice (Meta MMS-TTS, CC BY-NC 4.0) may not be used commercially, so Vuga is not sold. Each photograph keeps its own licence (photo credits), and so does each open-source library built into the app (third-party licences).
