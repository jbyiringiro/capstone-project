# Printable and laser-cut parts

- `keyguard/`: parametric OpenSCAD keyguard for the tablet board (rows, cols, bezel, hole size as parameters); exported STL per tablet model.
- `stand/`: tablet stand with cable channel.
- `enclosure/`: talker device enclosure for the chosen display.

All parts are printed at ALU Unipod or Fab Lab Rwanda. Licence: CERN-OHL-P v2 (permissive).
Files are added from week 5 alongside the talker device work.
