# Kinyarwanda core vocabulary

Target: 300 to 500 symbols, built from published AAC core lists (Banajee et al., 2003),
translated by two native-speaker content collaborators, mapped to ARASAAC pictograms
(CC BY-NC-SA 4.0, attribution retained) and recorded in two voices at 22 kHz mono WAV.

## Files

| File | Purpose |
|---|---|
| `symbols.csv` | One row per board symbol: `symbol_id, label_rw, label_en, category, arasaac_id, image_path` |
| `lexicon.csv` | Surface form to symbol mapping used by `ml/vuga_ml/mapping.py` (see column notes in that module) |
| `audio/` | `<symbol_id>_<speaker>.wav`; not committed; a manifest with durations is generated by `ml/scripts/audio_manifest.py` (week 4) |
| `decision_log.md` | Accepted, revised and excluded items with the reason, kept from week 4 onwards |

The current `lexicon.csv` and `symbols.csv` are **seed entries only**, written to let the
pipeline run end to end. Every row is replaced by the reviewed list before any result is reported.

## Symbol identifier rules

- Upper-case ASCII, words joined by underscore: `WANT`, `THANK_YOU`, `HE_SHE`.
- Grammatical persons are separate symbols (`I`, `YOU`, `HE_SHE`, `WE`) so that a conjugated
  Kinyarwanda verb (`ndashaka`) maps to `I + WANT` rather than to a single opaque cell.
- Negation is its own symbol `NOT`; a negated surface form must emit it (`sinshaka` -> `I NOT WANT`).
- Function words that have no cell on the board are marked `DROP` in the lexicon, never omitted silently.
